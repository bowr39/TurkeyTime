# Turkey Time
Phase 1 prototype for Godot 4. Import project.godot and press F6 from main.tscn or F5 to play. No external assets required.
Controls: A/D or arrows, Space jump, J peck, K punch, L flap, R restart.
This is a placeholder 2.5D test environment, not the finished Farmstead. Three instances of one enemy type, basic health, attacks and camera. Upgrade progression, final models, audio and additional enemy types are future work.
